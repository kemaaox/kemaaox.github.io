Software-defined networking (SDN) makes networks programmable, but network control applications still have to solve hard problems, such as finding paths that satisfy complex constraints or embedding requested topologies, with hand-written code. **SERPENT** explored representing network resources and state with semantic (RDF/ontology) models, so that these problems can be expressed as declarative queries and answered with semantic query processing.

This led to new work on *generalized path queries*: efficient evaluation of multi-source, multi-destination path queries and of queries that combine algebraic path problem solving with graph pattern matching.

**Funding:** NSF NeTS: Small: Collaborative Research award [CNS-1526113](https://www.nsf.gov/awardsearch/showAward?AWD_ID=1526113) (PI at NC State), in collaboration with RENCI.

**Selected papers**
* Evaluating Generalized Path Queries by Integrating Algebraic Path Problem Solving with Graph Pattern Matching. *SEMANTiCS 2019*.
* Evaluating Path Query Mechanisms as a Foundation for SDN Network Control. *IEEE NetSoft 2018*.
* PrefixSolve: Efficiently Solving Multi-Source Multi-Destination Path Queries on RDF Graphs by Sharing Suffix Computations. *WWW 2013* (earlier work on path queries).
